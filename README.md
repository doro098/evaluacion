# Aprender haciendo. 

**El rol del técnico: De la pasividad del consumidor a la autonomía del creador**

Un técnico en electrónica no es un usuario final; es un profesional que diseña, diagnostica e interactúa con la infraestructura crítica de los sistemas. En este nivel, esperar que el docente resuelva tareas operativas básicas —como descargar un instalador de internet, configurar una variable de entorno o leer un archivo ReadMe— es una actitud pasiva incompatible con el perfil profesional exigido. El conocimiento técnico actual no se memoriza: se investiga y se ejecuta de forma proactiva. Romper con el modo "consumidor de aplicaciones" y adoptar el rol de estudiante ACTIVO implica que el alumno debe ser capaz de autogestionar su entorno informático, experimentar sin miedo al error, buscar soluciones de forma independiente en la documentación y entender que configurar sus herramientas de software es el primer paso para dominar su propio hardware.
